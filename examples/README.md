# Examples

Choose the interaction you want:

| Tutorial | What you will do |
|---|---|
| [Your first shared robot session](shared-session.md) | Start one simulated robot, chat through the TUI, browser, or CLI, inspect saved images, and reconnect without losing the running session |
| [First task in simulation](first-task.md) | Give the agent one task with `openrua exec`, which records the run, or use its original terminal with `openrua agent` |
| [Your real robot](real-robot.md) | Connect a ROS 2 robot with `openrua connect` ([guide](../docs/connect.md)), which goes on into a conversation on it and makes it your default robot, or describe it in a profile yourself; then talk to the agent on it or record a run with `openrua exec`; hardware validation is separate from the simulation walkthroughs |

Start with [Install](../docs/install.md) for Docker, your agent's login, and
image preparation. For scored trials and experiment artifacts, use
[Running experiments](../docs/running-experiments.md).
